ASMR Bubble Wrap

Bubble wrap you can actually walk on. Every bubble squashes under your feet with a proper pop, re-inflates a few seconds later, and never sounds the same twice — the pitch and volume shift slightly on every pop, so a whole sheet doesn't turn into a machine gun.

Before you start

The free scripts run silently until these three things exist. If nothing pops, it is almost always one of these.

  1. Script 1 must be a ModuleScript named exactly ASMRCore, inside ReplicatedStorage. Script 2 looks it up by that name and will sit there doing nothing if it is spelled differently.
  2. Create a Folder in ReplicatedStorage called ASMRSounds and put your pop sounds in it, named Pop1, Pop2, Pop3 and so on. The name prefix is how variations get picked — no folder means no audio.
  3. Every bubble Model needs the attribute ASMRType set to the text Bubble, and at least one BasePart inside it. Models without the attribute are ignored completely.
